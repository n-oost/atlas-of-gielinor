# POI presentation and legacy inputs

The authoritative normalized records are in `../catalog/`: identities in `pois.tsv`, native positions in `locations.tsv`, and scalar alias/tag relations. Browse the joined view at `docs/map-catalog-audit.tsv`.

The `pois*.tsv`, curated details, requirements and teleport data here are retained migration snapshots. Runtime POIs no longer import them. Do not edit them as a second POI source. Icons, notices, display offsets and tooltip-name rules remain presentation resources. Structured travel networks retain their specialized loaders.
